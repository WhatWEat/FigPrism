# 012 — 检视器首帧尺寸、详情同步与拖动缩放

- **Status**: `In Progress`
- **Created**: `2026-11-14`
- **Target PRD Sections**: `§3.2`

## 1. 用户反馈

- 切图等待期间，右侧会显示上一张图的详情。
- NADS 首次打开先出现缩略图，高清到达前观感不一致。
- 放大范围不足，希望左侧有可拖动的缩放条。
- 加载与操作存在顿挫，需要改善体验。

## 2. 已核对事实

- NADS Fig.1 的原图和索引都是 7232×3200。
- 图像本身完整，分类保持方法主框架。
- 右侧图注存在未处理的 `$M_nav$` 等公式片段。
- 现有首帧适配依赖弹窗挂载后的尺寸监听。
- 缩放事件会频繁更新整块检视器 React 状态。

## 3. 本次范围

- 当前 Fig 元数据未到达时，右侧显示加载占位，不保留旧图详情。
- 已缓存的目标图元数据优先用于切换。
- 画布挂载时立即计算适配尺寸，缩略预览与高清保持同一画框。
- 缩放更新按 animation frame 合并，避免高频重复布局。
- 为缩放/取色更新隔离右侧详情渲染。
- 左侧新增垂直、可拖动的缩放条。
- 缩放范围扩大为 25%–3200%，保留适应窗口。
- 保留滚轮缩放、拖动平移和原始像素取色行为。
- 图注公式采用按需加载的数学排版，不显示裸露的美元分隔符。
- NADS 的简单长下标变量在显示层恢复正确排版。

## 4. 与并行任务边界

- 不改动分类标签或重新判图。
- 不修改 NADS 原始图像、图注数据库或 WebDAV 文件。
- 不重复实现 008 的资源 LRU/预取机制。
- 保留另一个任务已上线的 3 GB 服务端缓存：500 MB 收藏池 + 2.5 GB 普通池。
- 不变更池内 LRU、普通池长期保留和未备份文件保护规则。
- 本单专注首次画框、元数据状态、缩放与详情渲染。
- 保留已存在的方法/实验筛选和分类编辑功能。
- 不改动后端、并发配额和上传队列。

## 5. 安全与兼容

- 公式渲染不信任输入，不允许外链加载或 HTML 扩展。
- 设置公式展开次数和尺寸上限。
- 渲染失败时安全显示文本，不执行输入内容。
- 原始图像与取色值不受排版或缩放影响。

## 6. 验收

- 延迟目标详情响应时不会看到上一张图注。
- 缩略/高清切换前后画框尺寸稳定。
- NADS 图注变量显示为下标，而不是裸露源码。
- 滑条可从适应窗口放大到超过 500%。
- 拖动/滚轮缩放保留锚点且不反复重排右侧详情。
- 类型检查、生产构建和相关 E2E 通过。
- 记录首次高清仍受网络影响的实际限制。
- 用户验收后再合入主 PRD。
