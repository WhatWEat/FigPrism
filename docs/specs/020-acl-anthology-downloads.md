# 020 — 允许 ACL Anthology 官方论文下载

- **Status**: `In Progress`
- **Created**: `2026-11-17`
- **Target PRD Sections**: `§6 论文来源 / §8 外部输入安全`

## 1. 背景

- 现有论文下载白名单尚未包含 ACL Anthology。
- ACL / EMNLP 官方目录和 PDF 位于 aclanthology.org。
- arXiv 当前限流，需要通过官方论文站获取已录用论文。
- 本单只记录实际白名单变更，不为追加抓取批次数建单。

## 2. 范围

- 将 aclanthology.org 加入现有学术来源白名单。
- 沿用现有 fetch 与 fetch_metadata 下载入口。
- 不改变当前网络请求、重试与阶段预算。
- 不增加任意域名、通配域名或通用代理下载入口。
- 不改变前端论文导入支持的 URL 解析类型。
- 批次运行参数、候选与断点仅存 data/ops。

## 3. 下载契约

- 仅允许 HTTPS。
- 仅允许精确 hostname aclanthology.org。
- 保持禁止 URL 用户名和非标准端口。
- 每次重定向仍重新执行白名单检查。
- PDF 沿用单文件大小限制。
- 元数据调用显式设置响应大小上限。
- PDF 下载占用 download 阶段预算。
- 元数据下载占用 metadata 阶段预算。
- 不绕过远端服务限流。

## 4. 论文元数据

- 批次根据官方主会目录核对会议、年份与论文标题。
- 本次候选只取 ACL / EMNLP 主会，不把 Findings / Workshop 标为主会。
- 沿用现有 ingest_pdf 处理已下载字节。
- 沿用原有标题、文档标识和文件哈希去重。
- 不修改数据库结构或已有索引。

## 5. 安全与运维

- 不修改 WebDAV 目标或凭据。
- 不改变缓存容量与收藏池保护。
- 不修改分阶段并发上限。
- 不停止正在服务的 API 或其他入库批次。
- 只让新批次运行时使用更新后的下载白名单。

## 6. 验收

- 官方 hostname 请求可进入下载流程。
- 指向未批准 hostname 的重定向仍被拒绝。
- 原有后端测试通过。
- 以真实官方目录核对候选，启动后确认论文处理进度。
- 用户验收后再合入主 PRD。

## 7. 验证记录

- 后端 81 项测试通过，含官方下载及重定向白名单边界。
- Docker 后端镜像构建通过，仅用于新启动的批次容器，未重启线上 API。
- 官方 2026 ACL Long / EMNLP Main 目录各筛出 152 篇未入库、匹配现有领域的候选。
