# 016 — 合并检视器缩放工具

- **Status**: `In Progress`
- **Created**: `2026-11-16`
- **Target PRD Sections**: `§3.2 图表深度拆解抽屉`

## 1. 背景与痛点

- 左侧悬浮缩放条占用图像显示空间。
- 右上角同时存在一组缩放按钮，造成重复。
- 用户要求将拖动缩放与右上角工具合并。

## 2. 范围边界

- 移除画布左侧悬浮缩放栏。
- 在右上角原缩放工具中加入横向滑条。
- 保留一个倍率读数、一组加减按钮和适应窗口按钮。
- 保留吸管取色入口。
- 沿用现有缩放状态与动画帧合并逻辑。
- 不修改图片下载、解码或缓存策略。
- 不修改图表分类、右侧详情和导入流水线。

## 3. 交互与视觉增量

- 工具位置固定在画布顶部右侧胶囊内。
- 滑条横向拖动，向右放大、向左缩小。
- 倍率范围保持 25%–3200%。
- 保留对数刻度，便于调节较低倍率。
- 加减按钮沿用顶部工具的 25 个百分点步长。
- 达到上下限时禁用相应按钮。
- 适应窗口恢复 100% 并复位平移。
- 倍率读数预留固定宽度，避免数字变化挤动布局。
- 窄屏缩短滑条，必要时顶部工具换行。
- 暖纸底色和浓墨文字继续使用现有语义变量。
- Guest、User、Admin 均可使用缩放。

## 4. 数据、接口与命令增量

- SQLite 表结构变更：无。
- HTTP API 契约变更：无。
- 后台任务与 CLI 变更：无。
- 服务端缓存分池与未备份保护策略变更：无。
- 部署范围：仅 frontend 服务。

## 5. 验收与回归

- 左侧悬浮栏不再出现。
- 滑条与加减、倍率、适应窗口位于同一右上角工具组。
- 拖动、键盘、滚轮缩放继续同步更新倍率。
- 3200% 上限和 100% 复位有效。
- 移动端无横向溢出或控制项遮挡。
- 类型检查与生产构建通过。
- 运行现有检视器和取色相关 E2E。
- 通过后提交，并仅更新本地前端容器。
- 用户验收后再同步主 PRD。
