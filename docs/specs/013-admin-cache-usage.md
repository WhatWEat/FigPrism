# 013 — 管理后台缓存占用率

- **Status**: `In Progress`
- **Created**: `2026-11-15`
- **Target PRD Sections**: `§8 / §9 管理接口`

## 1. 背景

用户要求在 admin 后台显示两个缓存池的占用情况。
当前管理接口已返回缓存总量与收藏池用量，但管理页尚未展示。

## 2. 范围

- 在管理页增加“本地缓存”卡片。
- 分别展示普通缓存和收藏缓存。
- 展示已用空间、容量上限、百分比和进度条。
- 展示两池合计占用与总上限。
- 普通缓存用量包含待上传文件。
- 收藏池展示收藏图表的高清图和缩略图占用。
- 使用真实配置，不在前端硬编码 2.5 GB / 500 MB。
- 沿用现有管理状态查询的三秒刷新。
- 显示加载/错误状态，不把无法获取的数据显示为零。

## 3. 数据接口

- 沿用 GET /api/admin/pipeline 的 storage 对象。
- 增补 normal_used_bytes，避免前端和 CLI 重复推导。
- used_bytes、favorite_used_bytes、normal_used_bytes 使用同一次文件扫描。
- 保持原有字段兼容。
- 不新增数据库表，不修改缓存淘汰策略或容量。

## 4. 展示

- 普通缓存：已用 / normal_limit_bytes；占用百分比。
- 收藏缓存：已用 / favorite_limit_bytes；占用百分比。
- 总用量：used_bytes / limit_bytes。
- 使用十进制 KB / MB / GB，与配置容量一致。
- 零容量时百分比显示为零，不产生 NaN / Infinity。
- 窄屏两个缓存池上下排列。
- 使用暖宣纸语义变量、浓墨文字与现有品牌色。
- 进度条提供可访问名称与数值。

## 5. 权限和边界

- 仅管理员可见，保留现有管理员接口鉴权。
- 管理接口继续 private,no-store。
- 不暴露收藏归属或用户私有看板数据。
- 不涉及缓存清理、手动删除或容量编辑入口。
- 不修改其他草案规格单内容。

- [x] 自动刷新正确更新用量和占用率。
