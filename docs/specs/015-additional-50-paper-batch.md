# 015 — 追加 50 篇论文的独立批次

- **Status**: `In Progress`
- **Created**: `2026-11-15`
- **Target PRD Sections**: `§6 / §7.3 运维任务`

## 1. 本次授权

用户要求再启动一个多爬 50 篇论文的任务。
沿用当前 2026 年、激活领域和已录用会议筛选。
本次是运行态批次，不新增网页功能或修改缓存策略。

## 2. 批次定义

- 目标为额外成功入库 50 篇唯一论文。
- 启动时保存已完成论文的基线，当前为 157 篇。
- 已入库论文跳过，不占额度。
- 下载、解析或入库失败不计成功额度，继续补候选。
- 使用成功名额信号量，防止并发任务超过 50 篇。
- 原文与图表保持本地先行、异步远端备份。
- 原有 3 GB 总预算、500 MB 收藏池继续生效。

## 3. 来源与筛选

- CVF 官方 CVPR 2026 主会目录按标题和摘要匹配领域。
- arXiv 按激活领域召回，优先使用已带录用会议标记的候选。
- 排除不匹配领域或会议年份的论文。
- 保留真实作者、摘要、会议与官方来源链接。
- 不改变外网白名单与 PDF 安全限制。
- 候选分批进入有界队列，边发现边入库。

## 4. 运行与恢复

- 独立容器 figprism-extra-50，不依附网站 API 容器。
- systemd 管理服务，异常退出后自动恢复。
- 定期持久保存批次、已调度论文、成功 ID 与失败次数。
- 重启时核对已调度论文是否已经完成，防止重复计数。
- 进度通过现有 jobs 接口展示为“新增论文 X/50”。
- 每小时巡检识别此批次，期间不额外启动默认冷启动任务。
- 批次停止且目标未完成时，巡检恢复此批次。
- 达到 50 篇后完成退出，不继续添加。
