# 017 — 独立用户管理与缓存、资源统计

- **Status**: `In Progress`
- **Created**: `2026-11-16`
- **Target PRD Sections**: `§3.2 页面五 / §4 / §8 / §9 管理接口`

## 1. 背景

- 用户希望点开账号查看详情、收藏内容与收藏总量。
- “账号与邀请”从系统控制中心拆为独立页面。
- 缓存区需要命中率，以及包含 WebDAV 的资源大小。

## 2. 范围

- 新建 /admin/users 页面，仅管理员可访问管理数据。
- 移入邀请链接生成、用户启停与用户列表。
- 新增账号总览、用户详情弹窗与分页收藏列表。
- 系统控制中心保留流水线、领域配置、修图队列与缓存。
- 控制中心新增缓存命中统计与资源盘点。
- 不修改缓存容量、分池、淘汰和未备份保护规则。
- 不修改普通用户访问其他用户私有资源的权限。

## 3. 用户管理交互

- 管理员菜单与控制中心提供“用户管理”入口。
- 列表显示用户名、角色、启停状态和收藏图表数量。
- 点击详情显示注册时间、最近浏览时间和收藏概况。
- 概况包含看板数、收藏条目数、去重图表数、去重论文数。
- 收藏条目按收藏时间倒序分页。
- 显示图表缩略图、图号、论文标题、所属看板和收藏时间。
- 可按看板筛选收藏条目。
- 统计区区分收藏条目与跨看板去重后的收藏图表。
- 账号没有收藏时明确显示空状态。
- 切换用户时不显示上一位用户详情。
- 不返回密码散列、会话令牌或邀请密钥历史。

## 4. 缓存命中口径

- 统计服务端图表资产接口成功读取次数。
- HIT 为首次本地命中；MISS 为本次实际回源。
- COALESCED 为等待同资源回源后复用，单独计数。
- 命中率 = HIT / (HIT + MISS + COALESCED)。
- 展示统计起点、请求数、命中、回源与合并等待次数。
- 浏览器及 CDN 直接命中、不抵达服务端的请求不计入。
- 无请求时显示“暂无请求”，不把无数据解释为 0% 命中。
- SQLite 原子累加，跨进程共享且重启保留。

## 5. 资源大小口径

- 盘点应用 WebDAV 根目录下的文件大小，不下载文件正文。
- 使用 PROPFIND 文件长度和受限并发目录遍历。
- 盘点在后台运行，页面轮询不会重复扫描远端。
- 保留最近一次成功快照、更新时间、扫描状态和失败反馈。
- 首次访问自动盘点，之后提供手动刷新。
- WebDAV 用量为远端物理文件大小合计。
- 资源总量合并 WebDAV 与本地资产，按资产路径去重。
- 同路径存在本地版本时使用当前本地版本大小。
- 另列本地实际缓存量，避免与资源总量混淆。
- 范围包括论文 PDF、图表与元数据，不包含数据库和模型权重。
- 扫描失败不发布部分总量；保留上次有效值并标明错误。
- 未完成首次盘点时总资源量显示“盘点中/尚未盘点”。

## 6. API 与数据

- GET /api/admin/users：账号列表、每人收藏统计、总体统计。
- GET /api/admin/users/{uid}：详情、看板、分页收藏内容。
- 沿用 POST /api/admin/invites 与 PATCH /api/admin/users/{uid}。
- GET /api/admin/storage/insights：命中计数与资源盘点快照。
- POST /api/admin/storage/scan：启动后台盘点，运行中合并请求。
- 新增 cache_metrics 单行聚合统计。
- 新增 remote_assets 文件清单与 resource_scan 单行扫描状态。
- 所有新增管理接口 require_admin，响应 private,no-store。
- 不改变现有公开图表资产版本和缓存头契约。

## 7. 验收

- 游客、普通用户不可读取管理统计或他人收藏详情。
- 不存在的用户、越过用户归属的看板返回 404。
- 多看板重复收藏、空收藏、分页统计准确。
- 本地命中、实际回源、合并等待计数准确。
- 远端与本地重叠资源不重复计算。
- 盘点失败、重入与服务重启可恢复。
- 后端测试、类型检查、生产构建及相关页面回归通过。
- 按阶段提交，部署后验证；用户验收后再合入主 PRD。
