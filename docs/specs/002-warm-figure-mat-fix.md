# 002 — 修正图片区域偏白的固定纸感显示

- **Status**: `In Progress`
- **Created**: `2026-11-14`
- **Target PRD Sections**: `§3.1`

## 用户反馈

- 移除纸感开关后，图片区域看起来仍然偏白。
- 用户希望恢复原本偏褐的暖纸观感。
- 保持固定显示，不重新加入任何切换开关。

## 基线与诊断

- 现有展示图固定使用 `.fig-paper-blend`。
- 线上实际 `mix-blend-mode` 为 `multiply`。
- 线上图片装裱背景为 `rgb(250, 248, 245)`。
- 该背景接近纯白，白底论文图仍显得明亮。
- 现有画布暖灰褐 Token 为 `--bg-drafting: #E6E2DA`。
- 本次用户明确反馈优先于旧装裱色 `#FAF8F5`。
- 立项时主 PRD 与规格模板尚在整理，现已补读 `docs/PRD.md` §3.1。
- 本次以主 PRD 为基线，并按用户本轮明确反馈调整图片衬底。

## 增量范围

- 将 `--bg-figure-mat` 指向现有 `--bg-drafting`。
- 图片区域的最终背景应为 `#E6E2DA`。
- Deck 主图沿用统一装裱 Token。
- 胶片缩略图沿用统一装裱 Token。
- Swimlane 与 Flat 图片沿用统一装裱 Token。
- 详情大图与同文导航图片沿用统一装裱 Token。
- PDF 重切预览沿用统一装裱 Token。
- 保留固定 multiply 融合与 contrast(1.02)。
- 不加入纸感或纯白背景开关。

## 色彩保真

- 改动仅作用于显示层。
- 原始 WebP / PDF 资产不重新生成。
- 原始配色 HEX / RGB 数据不变化。
- 吸管继续读取离屏原始 canvas 像素。
- 不将偏褐显示像素写入取色历史。

## 验收

- 首页、详情图像白色区域呈暖灰褐色。
- 实际截图中检查原图白色区域的显示像素。
- 确认没有纸感与纯白背景切换按钮。
- 确认旧 localStorage 关闭偏好不影响显示。
- 原始像素取色断言继续通过。
- 前端类型检查与生产构建通过。
- 运行相关端到端回归。

## 发布

- 只部署前端服务，不重启后台导入进程。
- 验证后单独提交本次改动。
- 用户验收后再同步主 PRD 与规格状态。

## 已完成的验证记录

- 实际截图采样：原图白色 `(255,255,255)` 显示为 `(230,226,218)`。
- 离屏原始取色断言通过；没有重新引入开关。
- 已与检视器修正一起上线，等待用户视觉验收。
