# 011 — 移除首页分类引导横栏

- **Status**: `In Progress`
- **Created**: `2026-11-14`
- **Target PRD Sections**: `§3.2`

## 1. 背景与痛点

- 用户要求删除首页默认展示的分类引导横栏。
- 文案以“按图表使命分流精筛”开头。
- 横栏包含方法图和实验图的解释及快捷入口。
- 该区域在“全部精选”模式额外占用纵向空间。

## 2. 本次范围

- 移除整个引导横栏的可见展示。
- 同时移除该横栏占用的边框、内边距与外边距空间。
- 横栏内的两个快捷按钮一起撤下。
- 不增加替代横栏或新的提示文案。
- 不改变现有主分类标签的交互。
- 不修改方法图与实验图的专属精筛面板。
- 不涉及检视器、上传与后台任务逻辑。

## 3. 交互与视觉增量

- 默认进入首页时不再显示引导横栏。
- 返回“全部精选”时也不显示该横栏。
- 图表列表紧接已有工具栏和筛选区域。
- 桌面与移动端行为一致。
- 用户仍可通过现有方法图、实验图标签进入精筛。
- Guest、User 与 Admin 的主页展示一致。
- 沿用全站现有暖纸颜色与字体规则。

## 4. 实施约束

- 仅针对 `.taxonomy-panel.taxonomy-all` 撤下展示。
- 使用精确选择器，避免影响其他分类面板。
- 与当前并行开发中的分类模块保持兼容。
- 仅提交本单涉及的样式及规格记录。
- 不将其他未提交的分类功能纳入本次提交。

## 5. 数据与接口

- SQLite 表结构：无变更。
- HTTP API：无变更。
- CLI：无变更。
- 存储与并发：无变更。

## 6. 验收

- 首页不可见该文案及其所属横栏。
- 页面不遗留空白占位框。
- 方法与实验精筛入口仍可使用。
- 前端类型检查与生产构建通过。
- 线上浏览器检查通过后提交。
- 用户验收后再更新主 PRD 对应描述。
